# Sailaab: rules for every teammate's Claude

Hackathon project, 4 people, each with their own Claude. Deadline Sat Nov 28 2026, 9 PM (hard limit 11:59 PM).

1. Read `docs/PLAN.md`, `shared/CONTRACT.md` and the person's own part in `docs/parts/` before doing anything.
2. **Only edit files in your person's folder.** If something in `shared/` has to change, say so and let the human tell the group. Don't change another part's files.
3. Follow `shared/CONTRACT.md` exactly (field names, units, file paths). The other parts depend on it.
4. Explain what each piece does before building it. The humans have to pitch this live on Dec 2 and get asked questions.
5. Free tools only. No API keys in the repo. No Gemini or other paid models.
6. `git pull` before starting. Commit small with messages like `web: add house card`, and push often.
7. Keep it simple and working. A working demo beats a clever unfinished one.
8. Every new library, API or dataset goes in the README's "APIs, data and libraries used" table (that's a submission rule).
